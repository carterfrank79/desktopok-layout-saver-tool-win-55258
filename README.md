## About DesktopOK

DesktopOK is a lightweight Windows utility for saving and restoring desktop icon layouts. It is useful when screen setups change often, such as after resolution switches, docking and undocking, or moving between single and multi-monitor environments. Instead of rearranging icons manually each time, you can keep reusable layouts ready to apply when needed.

The tool is designed for users who want a simple way to preserve desktop organization without adding a heavy workflow. Its portable execution makes it easy to run from a folder or removable drive, and its tray-based operation keeps it accessible while staying out of the way. Command-line automation and language support also make it practical for repeat use in different setups.
